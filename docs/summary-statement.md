# Συνοπτική κατάσταση λογιστηρίου

Μετακινήσεις → Εκτ. Συνοπτικής Κατάστασης (`reports/summary-statement/`).
Επιλογές: περίοδος, ενεργός υπογράφων (προεπιλογή ο επικεφαλής), ημερομηνία εκτύπωσης.
Η προεπισκόπηση επιτρέπει εκτύπωση από τον PDF viewer. Η εξαγωγή κατεβάζει το ίδιο ενιαίο PDF.

## Περιεχόμενο

1. Συνοπτική κατάσταση ανά εργαζόμενο, χωρισμένη σε χωρίς/με ενεργή κράτηση ΜΤΠΥ, με σύνολα ανά κατηγορία και γενικό σύνολο.
2. Χωριστή κατάσταση απόδοσης ΜΤΠΥ με τις ίδιες κατηγορίες.
3. Χωριστή κατάσταση απόδοσης ΓΕΩΤΕΕ μόνο για τους υπαγόμενους εργαζομένους.

Κάθε κατάσταση αρχίζει σε νέα σελίδα και έχει σελιδοδείκτη PDF. Με πολλές εγγραφές οι πίνακες συνεχίζονται σε επιπλέον σελίδες με επαναλαμβανόμενη επικεφαλίδα.

## Ποσά και κρατήσεις

Χρησιμοποιείται ο κοινός υπολογισμός της αναλυτικής κατάστασης: μετακινήσεις με αναχώρηση εντός των ορίων της περιόδου, υπολογισμός συνδεδεμένος με εκκαθάριση, διαφορετικά τελευταίος οριστικοποιημένος πραγματικός, διαφορετικά τελευταία ενημερωμένη εκτίμηση. Παρωχημένες/ανύπαρκτες εκτιμήσεις και μετακινήσεις συνδεδεμένες με άλλη περίοδο εμποδίζουν την παραγωγή, με αναφορά εργαζομένου.

Κάθε κράτηση ενεργοποιείται μόνο όταν ισχύουν ταυτόχρονα `employee.has_mtpy/has_geotee` και `period.has_mtpy/has_geotee`. Τα ποσοστά προέρχονται από τις παραμέτρους `mtpy/geotee`. Εφαρμόζονται στην ημερήσια αποζημίωση, όπως στην αναλυτική κατάσταση. Πρώτα στρογγυλοποιείται η κράτηση κάθε εργαζομένου σε λεπτά (ROUND_HALF_UP) και μετά αθροίζονται οι κρατήσεις. Έτσι τα ποσά των καταστάσεων απόδοσης συμφωνούν με τα ατομικά παραστατικά.

Άγνωστη υπαγωγή εργαζομένου σε ενεργή κράτηση ή ελλείπον ποσοστό απαιτούν διόρθωση πριν από την εκτύπωση. Αν η περίοδος απενεργοποιεί ΜΤΠΥ, όλοι εντάσσονται στην κατηγορία χωρίς κράτηση. Εργαζόμενοι με μηδενικά ποσά παραλείπονται. Τυχόν λογιστική διαφορά εμφανίζεται σε ξεχωριστή στήλη προσαρμογών ώστε τα σύνολα να συμφωνούν.

Η παραγωγή δεν δημιουργεί εξόφληση, δεν κλείνει περίοδο και δεν οριστικοποιεί μετακινήσεις. Αν χρησιμοποιούνται εκτιμήσεις, αυτό αποθηκεύεται στην πηγή του αρχείου.

## Πρόσβαση και αρχείο

Στη διαχείριση «Χρήστες και δικαιώματα», στην ενότητα «Εκτ. Συνοπτικής Κατάστασης», απαιτούνται Εμφάνιση και Εκτύπωση. Απαιτούνται επίσης προβολή/εκτύπωση μετακινήσεων. Τα δικαιώματα της κατάστασης είναι ανεξάρτητα από τις χειροκίνητες λογιστικές προσαρμογές και δεν αποδίδονται αυτόματα σε χρήστες με δικαίωμα προσαρμογών. Το πεδίο ορατών εργαζομένων εξακολουθεί να εφαρμόζεται και αναγράφεται στο PDF. Η δυνατότητα λογιστηρίου δεν διευρύνει αυτόματα το πεδίο πρόσβασης.

Το `SummaryStatement` αποθηκεύει PDF, SHA-256, χρόνο/χρήστη παραγωγής και τις πηγές ποσών, ποσοστά, flags, αναγνωριστικά υπολογισμών/αναθεωρήσεις. Δεν αποθηκεύει ΑΦΜ ή IBAN. Η λήψη επανελέγχει τα τρέχοντα δικαιώματα και την πρόσβαση σε όλους τους εργαζομένους του αρχείου, χωρίς επανυπολογισμό του αρχειοθετημένου PDF. Η πρόσβαση και η παραγωγή καλύπτονται από την υπάρχουσα καταγραφή δραστηριότητας. Οι αποκρίσεις έχουν `Cache-Control: private, no-store`.

Migration: `0020_summarystatement`. Έλεγχοι: `python manage.py test core.test_summary_statement core.test_detailed_statement`.

## Shared report configuration

The application parameter organization_head selects the default Signatory for approval documents and both statements. The migration preserves the existing active is_head selection. Report forms can still select an active deputy. The shared signature title is prosfonisiproistamenou. Existing archived PDFs remain unchanged; generate a new report to use updated settings or branding. The statements use static/reports/ethnoshmo.png above the government header.
